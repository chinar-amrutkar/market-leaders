Signal definition

RS = Stock daily close ÷ SPY daily close

A breakout occurs when today's RS is strictly greater than the highest RS value across the preceding 250 trading sessions. The current session is excluded from that comparison. A ticker appears if it had at least one breakout in the latest 10 completed sessions.

Data and coverage

Prices are retrieved from TradingView's public screener feed through the Python tradingview-screener package. This is an unofficial interface and does not guarantee complete security-master coverage. Newly listed shares with insufficient history cannot qualify. Always review the chart before trading.
